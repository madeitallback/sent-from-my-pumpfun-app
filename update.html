Mise à jour des callouts

Un clic sur pump.fun, et les meilleurs callouts $App arrivent sur le site.

1. Le bouton (une seule fois)

Affiche ta barre de favoris (Ctrl+Maj+B, ou Cmd+Maj+B sur Mac), puis glisse ce bouton dedans :

↻ Callouts $App

Marche sur Chrome, Brave et Edge.

2. La clé GitHub (une seule fois)

  1. Clique sur ce lien (connecte-toi à GitHub si on te le demande). Le formulaire est déjà rempli.
  2. À Repository access, choisis « Only select repositories » puis le dépôt du site.
  3. Clique sur Generate token en bas, copie le code qui commence par github_pat_ et colle-le ci-dessous.

La clé reste dans ce navigateur uniquement. Elle ne peut modifier que ce dépôt.

3. Ensuite, à chaque mise à jour

Va sur la page du coin sur pump.fun et clique sur ↻ Callouts $App dans tes favoris. C'est tout : tu reviens ici, les callouts partent sur GitHub, et le site se met à jour tout seul en une minute environ.
